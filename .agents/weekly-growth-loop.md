# VR Academy Weekly Growth Loop

## Weekly Review Questions

1. How many qualified accounts were added?
2. How many first touches were sent?
3. How many replies arrived?
4. How many discovery calls were booked?
5. How many proposals were sent?
6. What objections repeated?
7. Which segment showed the most interest?
8. What should change next week?

## Scorecard

- qualified accounts added
- contacts added
- emails sent
- LinkedIn touches sent
- reply rate
- positive reply rate
- meetings booked
- proposals sent
- pilots won
- revenue won

## Weekly Decision Rules

If reply rate is under 3%:

- improve targeting first
- rewrite first line personalization
- test a clearer pain point

If positive replies happen but meetings do not:

- reduce friction in the call ask
- offer a 15-minute pilot-fit check
- include one concrete use case

If meetings happen but proposals do not:

- tighten discovery questions
- ask for worker count and pilot scenario during the call

If proposals do not close:

- simplify the pilot
- make success criteria clearer
- surface operational risk and management evidence

If materials are inconsistent:

- stop external sending from the affected material
- identify the current source of truth
- create a cleanup task before the next campaign

## Monthly Experiments

Run one experiment at a time:

- segment test: waste management vs construction vs industrial plants
- persona test: HSE manager vs training manager vs operations director
- offer test: paid pilot vs demo workshop
- content test: certificate proof vs incident-risk practice
- geography test: Serbia/Balkans vs EU industrial buyers

## Day 1-15 Cleanup Sprint

- align brand to VR Academy across external sales materials
- confirm which scenarios are demo-ready
- refresh sales deck pricing
- replace generic `mailto` contact path with structured intake when implementation time is approved
- define pilot package, hardware assumptions, support model, privacy wording, and proposal terms
